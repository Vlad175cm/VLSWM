# VLSWM — план работ

## 1. Окна: перестановка в стеке
- [ ] `SUPER+SHIFT+LEFT/RIGHT` — переставить сфокусированное окно с соседом по стеку.
- [ ] Фокус остаётся на переставленном окне.
- [ ] Клавиши задаются в `[keybinds]` (`swap_prev`, `swap_next`), не захардкожены.
- Проверка: окна меняются местами в порядке обхода `SUPER+LEFT/RIGHT`, сессия не падает.

## 2. Лаунчер: один кандидат, только .desktop
- [ ] Поиск только по `.desktop` (имена, GenericName, имя файла), без команд и `fish -c`.
- [ ] Под полем ввода — ровно одна строка: имя лучшего совпадения, без иконок.
- [ ] `Enter` запускает показанное приложение; если совпадения нет — ничего не происходит.
- [ ] `Terminal=true` по-прежнему открывается в отдельном окне foot.
- [ ] Пустой ввод — без подсказки.
- Проверка: «ze» → Zen Browser, Enter открывает; «zzzz» → пусто; команды больше не выполняются.

## 3. Ленивый Xwayland
- [ ] Убрать запуск `xwayland-satellite` при старте сессии.
- [ ] Запускать при первом запуске приложения; прогревать при открытии лаунчера.
- [ ] X11-приложения из лаунчера/биндов работают без задержки.
- Проверка: в простое нет `Xwayland`/`xwayland-satellite`; Telegram запускается; время старта X11-приложения не хуже текущего.

## 4. README: батарея/TLP
- [ ] Раздел про `CPU_SCALING_GOVERNOR_ON_BAT=powersave` + `intel_cpufreq` (частота 800 МГц под нагрузкой).
- [ ] Рекомендация `schedutil` + `CPU_BOOST_ON_BAT=1`.

## 5. OSD: громкость, яркость экрана, подсветка клавиатуры
- [ ] Чёрно-белый оверлей в углу, полоска + процент/значение, гаснет через ~1 с.
- [ ] Громкость (`wpctl`), яркость экрана (`brightnessctl`), подсветка клавиатуры (`brightnessctl --device=smc::kbd_backlight`).
- [ ] Работает с `XF86`-клавишами и `SUPER+F1..F4`.
- Проверка: каждое нажатие показывает актуальное значение, оверлей не мешает фокусу.

## 6. История буфера обмена
- [ ] `SUPER+SHIFT+V` — пикер истории.
- [ ] `cliphist` + `wl-paste --watch cliphist store` в автозапуске сессии.
- [ ] Список в чёрно-белом стиле: ввод фильтрует, `↑/↓` — выбор, `Enter` — копировать, `Esc` — закрыть.
- [ ] Зависимости в `install.sh` и README.
- Проверка: скопировал текст в одном окне — он есть в списке; выбор кладёт его в буфер.

## 7. HiDPI: масштаб в конфиге
- [ ] Ключ `[output] scale` (число, по умолчанию 1.0).
- [ ] Применяется при создании выхода и по `SUPER+R`.
- Проверка: `scale = 1.5` увеличивает интерфейс, размеры окон и терминала пересчитываются.

## Открытые вопросы
- Пункты 1 и 7 из обсуждения: окна fullscreen, поэтому «перетаскивание» = смена порядка в стеке. Подтвердить семантику фокуса.
- Лаунчер: точное совпадение или лучшее по подстроке.
- Буфер: нативный пикер или fuzzel.
- OSD: расположение и длительность.
